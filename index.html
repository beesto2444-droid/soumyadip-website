01 / Fundamentals

What is PHP?

PHP (PHP: Hypertext Preprocessor) is an open-source scripting language designed especially for web development. PHP code runs on a web server, which generates a response—often HTML—to send to the user's browser.

DYNAMIC CONTENT

Interactive Websites

Generate customized pages based on user input, sessions, and application data.

DATA HANDLING

Database Integration

Connect to databases such as MySQL to read, insert, update, and delete records.

BACKEND LOGIC

Server Processing

Validate forms, manage authentication, and handle application business rules.

02 / Request–Response Cycle

How Server-Side Programming Works

Unlike browser-side JavaScript, PHP executes on the server. The browser receives the resulting response, not the PHP source code.

Browser sends a request — A user visits a URL or submits a form.
Web server handles the request — PHP is invoked for the requested PHP script.
PHP processes data — The script may validate input, use sessions, or query a database.
Server returns a response — Usually HTML, but it can also be JSON or another format.
Browser displays the result — The user sees the generated page.
03 / Getting Started

Your First PHP Program

PHP scripts typically use the .php extension. PHP statements generally end with semicolons, and variables begin with a dollar sign ($).

Save this example as hello.php and serve it through a PHP-enabled web server.

hello.php
<!DOCTYPE html>
<html>
<body>
  <h1>My First PHP Page</h1>
  <?php
    $name = "Student";
    echo "Hello, " . $name . "!";
  ?>
</body>
</html>
PHP Form Processing Example (greet.php)
<?php
$name = trim($_POST['name'] ?? '');
$safeName = htmlspecialchars($name, ENT_QUOTES, 'UTF-8');
echo "Hello, " . ($safeName !== '' ? $safeName : 'Guest');
?>

Important: Escape output when displaying user input in HTML. For database queries, use prepared statements rather than concatenating user input into SQL.

Key Takeaway
